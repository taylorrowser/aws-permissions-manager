Node 18/20/22 test binaries were downloaded from official nodejs.org release
archives and checked against their published SHA-256 values. The Node 24.19.0
runtime was already available in the verification environment.
No runtimes or dependencies are bundled in this ZIP or installed by the helper.
Windows and macOS execution were not separately tested.

Security review:
- JWT signature, issuer, client, owner, session, lifetime and timestamp checks
  remain unchanged.
- Host/path pinning, TLS validation, response limits and redirect refusal remain.
- Token secrecy, private interactive-terminal checks and debugging restrictions
  remain unchanged.
- Refresh retry bounds, uncertainty handling and exact-session cleanup remain.
- An independent review found no required code fixes and additionally exercised
  the debugging/environment preflight and default monotonic-clock paths on
  Node 18.0.0 with network access intercepted.

The suite generates synthetic RSA keys and JWTs locally, uses mocked API
transport, and tests rejection of noninteractive live invocation before network
activity. It does not obtain real device, access or refresh tokens, prove live
sign-in/refresh/logout behavior, or wait out the one-hour server session limit.
