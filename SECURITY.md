# Security

Please report vulnerabilities privately by email to taylorrowser@outlook.com, not in a public issue
or pull request. Include what you found, how to reproduce it and what it lets someone do. I'll reply
when I can; this is a one-person project with no bug bounty.

In scope: this repository's code (the hosted service in `apm/`, the plugin in `plugins/`, the
workflows and the bootstrap template) and the IAM boundary it deploys. Weaknesses in AWS, WorkOS or
GitHub themselves should go to those vendors.
